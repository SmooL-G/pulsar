# Icons

These are generated by `npm run tauri icon -- ../web/public/icons/icon-512.png` from the project root.

The CI workflow `.github/workflows/desktop-release.yml` runs that step automatically before each Windows build, so you don't need to commit binary icon files here unless you want to override.

If a Linux dev wants to test locally:

```sh
cd apps/desktop
npm install
npx @tauri-apps/cli icon ../../apps/web/public/icons/icon-512.png
```

This populates `icon.png`, `icon.ico`, `icon.icns`, `32x32.png`, `128x128.png`, `128x128@2x.png`, plus the Microsoft Store sizes.
